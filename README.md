# Bomb Blitz Arena

Phaser arena game with bomber-style movement, bots, hazards, HUD, runtime smoke-test hooks, and AI validation.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Validate AI

```bash
npm run validate:ai
```

## Liivo Deployment

Build command: `npm run build`

Static output: `dist`

After deployment, add the Liivo URL to Noel's Game Hub under `bomb-blitz-arena`.
